A robot's wedding vow, in one line, for the [make.fun](https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b) micro-competition — love, through every update and every low battery.

`main.py` (Python standard library only) writes a single wedding vow — one line, no trailing newline — to `/output/entry.txt`.

## Run

```sh
python3 main.py
```
